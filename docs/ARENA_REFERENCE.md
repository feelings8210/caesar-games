# 球馆对标：头部 NBA 球馆的现场环境（2026-11-22）

Owner 问「你有没有去对标一些头部的现场环境设计」——之前没有，球馆是凭感觉调的。这份是第一次正式对标：
从 Wikimedia Commons 取 NBA 比赛现场照片（CC 授权），在浏览器里按区域量颜色和亮度，再拿游戏现状和
Blender 预览 a03 用同一方法量。以后改球馆、地板、观众、灯光都先对这份数。

## 量法

每张图手选矩形区域（地板木面避开油漆区和人、外圈 apron、观众 / 座椅、天花板），求平均 sRGB、
线性亮度 Y（0–1）、饱和度、色相，木面另求亮度变异系数 cv（纹理强弱）。参考照片是手机自动曝光，
**绝对亮度不可直接比，比例（地板 ÷ 其他）才是可比的**。样本只有 4 个球馆、区域是人工框的，数是方向性的。

## 目标（以后的验收数）

1. **地板是画面里最亮的大面积物体**：浅色枫木，接近奶白，暖黄不偏橙红。目标 sRGB ≈ (232–240, 214–220, 172–192)，饱和 0.16–0.29，色相 36–43°。
2. **木条看得见**：NBA 枫木条宽 2¼ 英寸（约 5.7 cm），近景能看到条缝和轻微色差；纹理 cv 约 0.09–0.11（不是 0）。
3. **地板 ÷ 观众 = 5–13 倍，取 8**：观众要暗，但不能黑成一片。
4. **地板 ÷ apron ≈ 8 倍**：apron 是饱和的深海军蓝，不是灰，也不是天蓝。
5. **地板 ÷ 天花板 = 15–40 倍**：天花板基本全黑，只有点状灯和桁架上的少量高光。
6. **舞台式布光**：光集中在球场上，出了 apron 迅速变暗；看台 2–3 圈 LED 环带、中央大屏是第二亮点。
7. 2K 的额外层次（以后做）：观众多样性和道具、顶部聚光、开场灯光秀、薄雾。

## 改法

- **游戏**：第一轮已完成（上表）。
- **Blender**：观众、天花板压暗；地板色相拉回 40°、更白；按 5.7 cm 木条做条缝与色差；apron 深海军蓝；
  只取地板和建筑结构，观众继续用游戏现有的真人观众贴片。
- 每次改完用同样的区域重量一次，进表。

## 2026-11-23 修订：地板目标改成"蜂蜜色"

Owner 看 a17 说地板"苍白、看不出质感"。量 a17：地板 Y 0.81、饱和 0.13、木纹 cv 0.04，亮到接近顶格，AgX 把高光的颜色冲淡了。上面 1–2 条目标取自手机自动曝光的照片，地板本身就被拍亮了，照着调会偏白。新目标以转播画面为准：色相 36–40°，饱和 0.27–0.32，木条明暗差清楚，面漆能映出广告牌和观众。

a18（`build_arena_venue.py` floor_material）：扫描木纹对比 +0.08（加到 0.45 会露出 2.5 英尺一格的贴图重复，像棋盘）；每条木条明暗 0.78–1.16；条缝 0.38；HSV 色相 0.55、饱和 1.55、明度 0.86；底色 (1.0, 0.85, 0.56)；面漆 0.85、粗糙 0.07。量得 broadcast 240,217,174 / 39° / 0.28 / Y 0.71；courtside 228,204,163 / 38° / 0.29 / Y 0.63。终版 SSD `arena-final-a18/`，对比图 `floor-compare-a17-a18.jpg`。
