# 动作拍摄清单（2026-11-23）

拍出来的视频会在 3090 上转成动作，再套到游戏球员身上。CMU 动作库已经补上了跑、急停、防守滑步、转身、假动作、突破和运球，所以这份清单只列 CMU 里没有或质量不够的动作。

## 怎么拍（最重要）

1. **手机横拍，每秒 60 帧**（1080p 或 4K 都可以）。
2. **固定机位**：三脚架或放在台子上，高度大约到胸口；离人 5–8 米。尽量不要跟拍转动手机。
3. **角度**：站在侧前方大约 45 度，不要正对着人，也不要正侧面。
4. **全身入镜，脚一直在画面里**：头顶和脚下各留一点空，人跑出画面那一段就用不了。
5. **画面里只有一个人在做动作**，别人不要从前面走过、挡住。
6. **衣服和地板颜色分开**：浅色木地板就别穿米色；短裤、球鞋都可以。
7. **每个动作做 3–5 遍**，每遍之间站直停 2 秒；有左右之分的，左右各拍一组。
8. 需要球的动作就带球做。我只取人的动作，球之后由我加。
9. 每段开拍前可以口头说一句动作名，方便我对号。

一组大约 40 个片段，拍一个小时左右。先拍"第一优先"那组就够我开始用了。

## 第一优先（游戏里最常出现）

| # | 动作 | 说明 |
|---|---|---|
| 1 | 接球跳投 | 接队友传球后直接起跳投篮，左右两侧各拍 |
| 2 | 运球急停跳投 | 运两三下，急停，起跳出手 |
| 3 | 右手上篮 | 从右侧运球进去，三步上篮 |
| 4 | 左手上篮 | 从左侧，同上 |
| 5 | 胸前传球 | 原地，双手胸前传出去 |
| 6 | 击地传球 | 原地，球在地上弹一下传出去 |
| 7 | 接球三威胁 | 接球后站成三威胁姿势，停一两秒 |
| 8 | 掩护 | 站定做掩护（脚开、双手护胸），然后转身顺下 |
| 9 | 卡位抢篮板 | 背身顶住、找人，然后起跳双手抓球落地 |
| 10 | 防守扑上（closeout） | 从篮下冲向射手，小碎步刹住，一手举高 |
| 11 | 封盖投篮 | 原地起跳，单手高举封盖 |
| 12 | 无球站立待机 | 自然站着、轻微晃动、看场上，拍 10 秒以上 |
| 13 | 防守待机 | 半蹲防守姿势，原地小幅移动，拍 10 秒以上 |

## 第二优先（丰富动作）

| # | 动作 | 说明 |
|---|---|---|
| 14 | 后撤步跳投 | 运球后撤一步再投 |
| 15 | 欧洲步上篮 | 左右各一组 |
| 16 | 反手上篮 | 从篮下另一侧出手 |
| 17 | 罚球 | 完整的罚球动作，含拍球、瞄准 |
| 18 | 头顶传球 / 单手推传 | 各一组 |
| 19 | V 字切 / 背切接球 | 无球跑位，切出来接球 |
| 20 | 掩护后外弹接球 | 做完掩护往外拉开接球 |
| 21 | 后退防守（退防跑） | 面朝前场倒退跑 |
| 22 | 协防后回位 | 往中间收一步，再滑回原位 |
| 23 | 背身单打 | 背身运球、转身 |
| 24 | 庆祝 / 击掌 | 进球后挥拳、两人击掌 |

## 不用拍的（CMU 已经有）

直线跑和变向跑、跑动中急停、横向滑步、Z 字防守、原地启动突破、左右突破、运球转身、假动作晃开、投篮假动作后突破、轴心脚转身、各种运球（前进、后退、横移、胯下、变向）。

## 拍好之后

把视频放进 MiniStorage 上任意一个文件夹，或者直接发给我，我来剪片段、转动作、套到球员上，再做和原视频的对比片给你看。
