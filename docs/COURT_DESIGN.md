# CD Games 主场地板设计（2026-11-23）

Owner 要求："地板的设计、颜色、质感、花纹，参考 NBA 那些主场，做一个属于我们的设计。"

## NBA 主场的共同做法（我们照着做的部分）

- 地板是浅色天然枫木，木条顺着球场长边铺。整块地板最后都会盖一层聚氨酯面漆；不管木头是本色、染色还是上漆，表面质感都一样（Wood Floor Business、ESPN 对 Connor Sports 等地板厂的报道）。
- 三分线外比线内深一档（两色染色），任何机位都能看清三分弧。湖人、勇士、快船现役地板都是这样，量法见 `docs/ARENA_REFERENCE.md`。
- 禁区涂球队主色；中圈放大号队标；队名印在端线外的外圈上，外圈本身也涂成球队色。
- 地板和外圈同色时，NBA 允许边界线加宽到 4 英寸；不同色时是 2 英寸。我们是浅木配深蓝外圈，所以用 2 英寸。
- 近几年的新地板常把图案用深一点的染色"刻"进木头里，远看是木纹的一部分，近看才认得出来。例子：2025-26 NBA 杯开拓者中圈的风车、爵士的山脉。

## 我们自己的部分

- **蚀刻战术图（招牌）：**每个半场都用很淡的深色染色（透明度 0.15），像粉笔一样画一套牛角战术：1 号在弧顶，4、5 号在罚球线两肘，两名射手在底角；4 号掩护，1 号运球突破，4 号顺下，1 号击地传球。游戏讲的是读防守，这套图把这件事写进了地板。
- **禁区：**海军蓝底，叠一层同色系、更亮一点的箭头纹，箭头指向篮筐，意思是"往里打"；禁区内侧有一道金色细线。
- **中圈：**海军蓝圆底，内侧一圈金色细环，中间是金色 CD 标。中线只画到中圈外沿，不穿过队标。
- **外圈：**海军蓝（sRGB 31,52,89，与 `docs/ARENA_REFERENCE.md` 的目标一致），边界线外 8 英寸有一道 4 英寸宽的金边。
- **文字（Anton 字体）：**两条端线外各印一个白色 HOOPS IQ，字头朝外，从场内看是正的；转播机位一侧的边线外印白色 CD GAMES，对面一侧印金色 HOOPS IQ，两处都按转播机位方向摆正。
- **标线：**白色 2 英寸。包括禁区、罚球圈（圈外半实线、圈内半虚线）、4 英尺合理冲撞区、抢位标记、距端线 28 英尺的教练区标记（伸出边线 3 英尺）。

## 实现

- `tools/court/make_court_design.py`：在 3090 上运行（矢量用 pycairo 画，抗锯齿；文字和队标用 Pillow）。输出一张 RGBA 贴图，覆盖 x -35..35 英尺、z -12..106 英尺，每英尺 64 像素，尺寸 4480×7552。alpha 表示油漆盖住木头的程度：0 是裸木，约 0.15 是染色，约 0.94 是油漆，油漆下仍能隐约看到木纹。
- **Blender：**`assets.json` 里加 `court_design` 后，`floor_material` 会把这张贴图混合到枫木木条上；原来用几何体画的染色、外圈、禁区、标线、文字和队标就不再生成。
- **游戏：**`js/games/hoops/courtdesign.js` 画半场，同一套设计里加了禁区箭头纹和蚀刻战术图（`etchedHorns`），两色染色和金线原来就有。
